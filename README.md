# Calculadora em Java com Enums e Functional Interfaces

Uma aplicação de calculadora via terminal desenvolvida em Java para demonstrar o uso de **Enumerations (Enums)** integrados a **Functional Interfaces (`BiFunction`)** para a execução de operações matemáticas dinâmicas de forma limpa e sem o uso excessivo de estruturas condicionais.

## 🛠️ Tecnologias Utilizadas

- **Java 11+**
- **IDE** (IntelliJ IDEA, VS Code, Eclipse ou terminal de sua preferência)

## 🚀 Funcionalidades

- **Soma (`+`)**
- **Subtração (`-`)**
- **Multiplicação (`*`)**
- **Divisão (`/`)**
- **Validação de entrada:** Proteção contra seleções fora do intervalo do menu (opções de `1` a `5`).
- **Encerramento seguro:** Opção dedicada para sair do loop e finalizar o programa corretamente.
